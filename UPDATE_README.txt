AC Calculator — نظام التحديث
================================

الإصدار الموجود في هذه الحزمة: 1.0.0

ما تم إضافته:
- فحص تلقائي عند تشغيل البرنامج بعد 1.5 ثانية إذا كان الإنترنت متاحًا.
- زر 🔄 تحديث للفحص اليدوي.
- نافذة تعرض رقم الإصدار وملاحظات التحديث.
- مقارنة إصدارات مثل 1.0.0 و1.1.0 و1.2.0.
- ملف update.json جاهز.

مهم: MediaFire مناسب لتحميل APK، لكنه ليس مكانًا مناسبًا لفحص نسخة JSON تلقائيًا. لذلك يجب استضافة update.json على رابط HTTPS عام يدعم عرض النص/JSON (مثل GitHub Pages أو أي استضافة ملفات نصية عامة).

بعد أن تستضيف update.json:
1. افتح updater.js.
2. استبدل https://YOUR-UPDATE-URL-HERE/update.json بالرابط الحقيقي.
3. ابنِ APK جديد من WebInto.
4. عند كل تحديث لاحق: ارفع APK جديدًا إلى MediaFire، ثم عدّل update.json فقط:
   - version: رقم أكبر، مثل 1.1.0
   - download_url: رابط MediaFire الجديد
   - notes: مميزات وإصلاحات النسخة
5. في WebInto استخدم نفس Package Name ونفس توقيع التطبيق، واجعل رقم إصدار Android أعلى من السابق، حتى يُثبت كـUpdate وليس كتطبيق منفصل.

تنبيه Android: زر تحديث الآن يفتح رابط APK. بعد التحميل قد يطلب Android من المستخدم فتح الملف والسماح بالتثبيت من المصدر المستخدم. صفحة HTML/JavaScript لا تستطيع تثبيت APK بصمت في الخلفية.
